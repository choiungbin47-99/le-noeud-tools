# le nœud — 목공 계산기 (PWA)

현장에서 쓰는 목공 계산기 9종. 인터넷 없이 동작하고, 폰 홈 화면에 앱으로 설치됩니다.

## 폴더 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (화면 + 계산 로직, 외부 파일·인터넷 불필요) |
| `manifest.webmanifest` | 앱 이름·아이콘·시작화면 정보 |
| `sw.js` | 서비스워커 — 앱을 캐시해 오프라인에서 열리게 함 |
| `icon-192.png` / `icon-512.png` | 홈 화면 아이콘 |
| `icon-maskable-512.png` | 안드로이드 원형·스퀘어클 아이콘용 |

## 담긴 계산기 9종

1. **목수 삼각형** — 밑변·높이·빗변·각도 중 2개 → 나머지 + 경사도 + 물매(치)
2. **재단 최적화** — 원판·톱날 두께·부재 목록 → 배치도 + 톱질 순서 + 자투리
3. **합판 장수** — 부재 크기·개수 → 1장에 몇 개, 총 몇 장, 금액
4. **각재 자르기** — 각재 길이·필요 토막 → 몇 토막, 자투리 몇 mm (FFD 최적화)
5. **페인트 양** — 벽 크기·칠 횟수 → 면적, 리터, 몇 통
6. **계단** — 층높이·단 수 → 챌판 높이, 디딤판 나비, 경사각, 2R+G 적정 판정
7. **일당 정산** — 일당·공수·공제 → 실수령액
8. **자재비 견적** — 수량·단가 → 부가세 포함 합계 (복사 기능)
9. **단위 환산** — 자·치·푼·mm·cm·m·인치(분수 표기)·피트

## 주소

**https://choiungbin47-99.github.io/le-noeud-tools/**

GitHub Pages로 배포돼 있습니다 (저장소 `choiungbin47-99/le-noeud-tools`, 무료·배포 횟수 제한 없음).
`index.html`을 더블클릭해 여는 방식(file://)으로도 계산기는 다 되지만,
「홈 화면에 설치」와 오프라인 캐시는 위 https 주소에서만 작동합니다.

### 고친 내용을 반영하려면

```bash
git add -A && git commit -m "수정 내용" && git push
```

push하면 1분 안에 위 주소에 자동 반영됩니다.
단, `sw.js`를 고쳤다면 맨 위 `CACHE = "lenoeud-v1"`의 숫자를 올려야
이미 설치된 폰이 옛 버전을 계속 쓰지 않습니다.

### 폰에서 설치

- **아이폰(사파리)**: 아래 공유 버튼 ⬆︎ → `홈 화면에 추가` → `추가`
- **안드로이드(크롬)**: 앱을 열면 나오는 `홈 화면에 설치하기` 버튼, 또는 ⋮ → `앱 설치`

설치하면 비행기모드·지하 현장에서도 그대로 열립니다.
